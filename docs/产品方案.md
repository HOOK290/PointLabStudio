# PointLabStudio — 产品说明

桌面点云工作站，v1.0.0。打开 → 查看/测量 → 处理/配准 → 导出。

## 1. 定位

- 开箱即用，无需脚本。
- 常见格式直接读，字段不丢。
- 千万级流畅浏览，上亿点流式采样。
- 结果可导出或存为工程继续编辑。

## 2. 系统要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11 64 位 |
| Python | 3.11+ |
| 显卡 | Vulkan 或 DirectX 12 |
| 磁盘 | 依赖约 1.3 GB |

## 3. 功能

### 3.1 数据管理与工程

- 场景列表：显示/隐藏、重命名、删除、重载。
- 拖入文件或目录批量打开。
- 最近文件、上次目录记忆。
- `.pls` 工程保存点云引用、相机、裁剪范围与派生数据。

### 3.2 自动分级加载（Auto-Ingest）

| 规模 | 策略 |
| --- | --- |
| <100 万点 | 同步载入 |
| 100 万–5000 万点 | 预览先行，后台全量后替换，可取消 |
| >5000 万点 | 采样预览并标注比例 |
| >1 亿点 | 八叉树分块流式，仅载入采样点，保留强度 |

多文件加载限流排队。

### 3.3 3D 显示

- pygfx / wgpu 渲染，脏标记按需重绘。
- 按视距 LOD。
- 颜色：默认、高度、强度、标量场、RGB、标签、单色。
- 颜色条带直方图，手动值域或 2%–98% 自动拉伸。
- 裁剪范围线框预览。
- 点大小、深浅主题、窗口布局记忆。

### 3.4 处理命令

体素降采样、随机采样、SOR、ROR、盒式裁切。统一参数校验，可撤销/重做。

### 3.5 分割与配准

平面分割、地面提取、DBSCAN、点到点 ICP、点到面 ICP、FPFH + RANSAC、4×4 矩阵编辑。

### 3.6 几何与网格

法线估计、C2C、C2M、Poisson 重建（网格可入场景参与渲染与 C2M）。

### 3.7 测量与选择

- 测量：折线累计长度与面积（Newell 法），区域半透明填充，导出 CSV。
- 选择：单击选点查看属性，或框选；选中点可提取或删除。

### 3.8 IO 与格式

| 格式 | 读 | 写 | 说明 |
| --- | --- | --- | --- |
| PLY | ✅ | ✅ | 全部标量字段 |
| PCD | ✅ | ✅ | binary / ascii |
| XYZ / XYZN / XYZRGB | ✅ | ✅ | 字段名自动识别 |
| PTS | ✅ | ✅ | 支持强度 |
| LAS | ✅ | ✅ | 1.2，点格式 0/1/2/3/6/7/8 |
| LAZ / E57 | ✅ | — | 需 `laspy`、`lazrs`、`pye57` |
| NPY / NPZ / TXT / CSV | ✅ | — | 数值矩阵 |
| BIN | ✅ | — | 维度自动识别 |

导出不烘焙显示伪彩，原始字段保留。

### 3.9 批处理与脚本

- 处理链：多命令串接，可导入/导出 JSON。
- 脚本控制台：逐行执行命令。
- CLI：`python -m apps.cli`，支持 `--stage`、`--commands`、`--export`、`--info`。
- 插件：`.py` 放插件目录，`register(api)` 注册命令。

## 4. 技术要点

### 4.1 分层

`core/` 领域层（数据、IO、算法、命令），`ui/` PySide6 与 pygfx 视口，`apps/` 桌面与 CLI 入口。

### 4.2 线程与性能

加载与处理在后台线程；视口按脏标记渲染并按视距降采样。

### 4.3 数据模型

点云 = 坐标数组 + 命名字段表；字段与坐标同生命周期，命令处理后保留。

## 6. 性能实测

RTX 5060 + Windows 11：

- 1000 万点离屏 407 FPS；主窗口 520 万点约 30 FPS。
- 6.6M 点加载约 4 秒。
- 体素降采样 6.6M → 940k 点 2.69 秒；地面提取 20 万点 0.11 秒。
- 1 亿点（1.6 GB）流式采样约 42 秒 → 80 万点。
- LAS 往返误差 <1 mm，字段精确往返。

## 7. 已知限制

1. 裁剪走 CPU 掩码，超大点云较慢。
2. >5000 万点为采样预览。
3. 平面主导场景的 ICP 可能绕竖直轴退化，先试 FPFH。
4. DBSCAN 在连续表面易碎簇。
5. 拾取为投影缓存近似，遮挡不完全精确。
6. LAZ / E57 需自行装依赖。
