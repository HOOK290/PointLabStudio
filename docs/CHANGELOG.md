# 变更记录

本文件按审查报告的执行清单（26 项）记录 v0.7 的落地内容。每一项都有对应的自动化测试或实测数据。

## v0.8.1（2026-10-31）

### 交互手感
- **旋转更可控**：水平拖拽严格绕世界 Z 轴（转盘），垂直拖拽做俯仰；灵敏度从 0.46°/px 降到 0.26°/px，按住 Shift 再降为 1/4。
- **不再翻转**：俯仰限制从 ±83° 收紧到 ±80°，相机始终保持 Z 轴朝上，连续大幅拖拽不会越过极点。
- **滚轮平滑缩放**：滚轮只写目标距离，渲染循环按指数阻尼逐帧逼近（单帧最多 30%），到位后才刷新 LOD，消除“一格一跳”和点密度突变。
- 新增 3 项回归测试（阻尼缩放、水平拖拽不改俯仰、俯仰限位不翻转），全量 `166 passed`。

## v0.7（2026-10）

### A 工程基线
- `903e334` git 初始化与 v0.6 基线入库（`.gitignore` 排除环境、数据与临时目录）。
- `647c1b1` `pyproject.toml`、带上限的 `requirements.txt`、精确锁定的 `requirements-lock.txt`；
  统一测试入口 `tools/run_tests.py`（含受限 Windows 沙箱的临时目录兼容）。

### B 数据保真
- **导出保字段**：原生写 PLY / PCD / XYZ / PTS，保留全部标量场，不再烘焙显示伪彩。
- **读入保字段**：原生解析 PCD（binary/ascii）、PLY（binary LE/BE、ascii），保留 intensity / labels / normal / rgb。
- **预览守卫**：预览点云派生的结果继承 `loaded` 比例与 tier，info 标注“基于 N% 预览”。
- **工程 v2**：`.pls` 保存相对路径、相机、裁剪范围与派生点云（`.assets/*.npz`），兼容 v1。

### C 性能与稳定性
- **脏标记渲染**：仅在场景/相机变化时提交帧，空场景不再持续渲染。
- **颜色缓存**：`refresh()` 增量更新，点大小只改材质；不再每次重算百分位并重建 GPU 缓冲。
- **加载队列**：最多 2 个后台加载线程，其余排队，槽位释放自动续跑。
- **可取消任务**：RANSAC / DBSCAN / ICP / 滤波 / 处理链 / 分块读取均支持取消；关窗最多等待 3 秒。
- **DBSCAN eps** 后台估算（≤20 万点仍同步），带缓存。
- **拾取**：投影缓存 + 近似遮挡；**裁剪**：非法 min/max 拒绝应用并提示。

### D 命令内核
- `Command` 数据类、`ParamDef`/`CommandSpec` 注册表、JSON 序列化；8 个内置命令统一实现。
- 撤销/重做、处理链、CLI、脚本控制台共用同一内核；处理链支持双击改参与 JSON 导入导出。
- CLI：`--commands FILE`、`--print-commands`、`--list-commands`。

### E 交互与能力
- **框选 / 套索**选择点云，橙色高亮，可提取或删除选中点。
- **测量**：连续点击累计折线，显示长度与 Newell 法面积，可导出 CSV。
- **标量场体系**：任意一维字段着色，颜色条 + 直方图，手动/自动值域。
- **配准增强**：点到面 ICP、FPFH + RANSAC 全局配准、4×4 变换矩阵编辑器。
- **设置/日志**：主题、最近文件、窗口几何、上次目录持久化；滚动日志；关于对话框。
- **LAS / LAZ / E57**：LAS 原生读写；LAZ/E57 缺依赖时给出明确安装提示。
- **LOD**：按视距三档渲染预算，索引稳定不闪烁。
- **法线 / 网格 / C2C / C2M**：法线估计、C2C、C2M、Poisson 网格重建与导出。
- **插件 / 崩溃恢复 / i18n**：`register(api)` 插件命令自动进入 UI 与 CLI；崩溃标记与异常日志；中英文案脚手架。
- 按需求**不打包**安装程序；LAZ/E57 保持可选依赖。
